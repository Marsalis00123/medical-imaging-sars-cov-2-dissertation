# Metode noi de prelucrare a imagisticii medicale pulmonare la pacienții infectați cu SARS-CoV-2

Repo de prezentare pentru lucrarea mea de disertație, realizată în cadrul programului de master **Biofizică medicală și biotehnologie celulară** la Universitatea de Medicină și Farmacie „Carol Davila” București, Facultatea de Medicină, în 2021.

Lucrarea abordează prelucrarea imagisticii medicale pulmonare în contextul infecției cu SARS-CoV-2.

## Documente

- [Lucrarea de disertație](docs/disertatie.pdf)
- [Prezentarea](docs/prezentare.pptx)
- [Pagina GitHub Pages](https://marsalis00123.github.io/disertatie-umfcd/)

## Ce conține repo-ul

- `docs/disertatie.pdf` - versiunea finală a lucrării de disertație.
- `docs/prezentare.pptx` - prezentarea pentru susținere.
- `docs/index.html` - pagina statică de prezentare pentru GitHub Pages.

## Domeniu și confidențialitate

Repo-ul public este limitat la documentele finale selectate și pagina de prezentare. Fișierele de lucru, seturile de date și materialele clinice separate nu sunt incluse.
